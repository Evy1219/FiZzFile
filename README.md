# FiZzFile

Offline QR transfer page for text, links, and file payloads using sequenced QR frames.

## Usage

1. Open `index.html` in a browser on the sending device.
2. Choose Text/URL or File.
3. Prepare the transfer and start sending.
4. Open `index.html` on the receiving device, switch to Receive, and allow camera access.
5. Scan each QR frame until the transfer completes.

## Notes

- Works fully offline with no internet required.
- Uses multi-frame QR transfers for longer payloads.
- Received files can be downloaded once the transfer finishes.
